Informácie pre developerov

GitHub Actions každé dve hodiny kontroluje farské príspevky. Python z ich HTML tabuliek vyberá dátumy, časy, obce a vybrané poznámky. Pri oprave pôvodného príspevku sa upraví aj uložený rozpis.

GitHub Pages zobrazuje statický web, ktorý číta poriadky.json a používa časové pásmo Europe/Bratislava. Pri výpadku zdroja ostanú dostupné posledné uložené údaje s pôvodným rozsahom dátumov.
